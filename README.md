# Земля в расчёте

Статический калькулятор предварительной оценки сделки по продаже права аренды земельного участка.

## Возможности

- Ручной ввод аналогов и реальных сделок.
- Расчёт расходов, прибыли и доходности для модельного участка 10 соток.
- Сравнение с кадастровой стоимостью и сценарии 6, 9 и 12 месяцев.
- Сохранение истории в текущем браузере.
- CSV для Excel и сохранение PDF через печать браузера.

HTML, CSS и JavaScript без сборки и серверной части.
Для локального запуска откройте `index.html`, оставив CSS и JS в той же папке.

## Данные

Автоматические интеграции, регистрация и оплата не подключены.
Демонстрационный пример содержит исключительно вымышленные данные.
Пользовательские расчёты хранятся в localStorage браузера и не отправляются на сервер.
При наличии интернета шрифт загружается из Google Fonts; без него используется системный шрифт.

Это предварительная экономическая оценка, без проверки юридической доступности участка.
Продажа, сроки и доходность не гарантируются.
