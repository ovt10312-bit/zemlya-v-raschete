# Земля · Навигатор

Адаптивное веб-приложение для личной работы с земельными участками. Карта, фильтры, карточки, калькулятор, история, избранное, импорт новых заявлений из Excel, разбор текстовых PDF с подтверждением и статистика.

## Открыть на своём компьютере

1. Установите Node.js 24 LTS (https://nodejs.org/).
2. Скачайте исходный код и распакуйте архив. Откройте терминал в папке с этим README.
3. Выполните последовательно:

```sh
npm ci
npm run build
npm start
```

4. Откройте **http://127.0.0.1:8787** в браузере.
5. При первом запуске создайте кабинет: почта и пароль от 12 символов. Следующие входы сохраняются на 30 дней.

Для остановки нажмите Ctrl+C. Повторный запуск: `npm start`.

Данные хранятся в `.data/` рядом с программой. Не удаляйте папку; для резервной копии остановите программу и скопируйте её целиком. JSON-выгрузка в интерфейсе не содержит исходных PDF — они входят в копию `.data/`.

Локальный сервер слушает только этот компьютер. На телефоне используйте опубликованную закрытую версию: локальный адрес 127.0.0.1 с другого устройства не доступен.

## Что работает

- 9 регионов, 6–20 соток, ИЖС / ЛПХ / садоводство; два типа поиска.
- Карта OpenStreetMap, область поиска двумя кликами, карта / таблица / совмещённый вид.
- Отдельный явно обозначенный демонстрационный режим. Примеры вымышлены и не попадают в рабочую статистику.
- Серверная история, избранное, постоянные ID и версии экономики.
- Формула меньшей медианы × 0,8 ÷ 2 × фактическую площадь; расходы и неизвестные значения отдельно.
- XLSX-экспорт с ID, проверками и аналогами; обратный импорт новых заявлений с проверкой строк и без дублей.
- PDF-отчёт через окно печати браузера: выберите «Сохранить как PDF».
- Разбор текстового PDF в браузере, хранение оригинала, редактирование полей, подтверждение одного или нескольких ответов.
- Статистика только по рабочим данным; согласование и фактическое предоставление — отдельные этапы.
- Локальный вход по почте и паролю, серверное хранение SQLite и файлов.
- Подтверждение почты через Mail.ru: настройка SMTP в кабинете, одноразовая ссылка на 24 часа, повторная отправка не чаще раза в минуту.
- Закрытое размещение Sites: вход через ChatGPT, данные в D1, PDF в R2.

## Существенные ограничения первой поставки

**Полноценный автоматический поиск свободной земли пока не подключён.** Прямой сервис пересечений НСПД подтверждён пользовательским отчётом для трёх категорий; поиск НСПД по названию получал 403. Авито, ЦИАН, Telegram-бот и docs.cntd.ru пока не подключены. Реальный запуск без провайдера сохраняет недоступность источника и не создаёт участки. Нормативная актуальность и правовая доступность автоматически не подтверждаются.

Дополнительные способы наполнения: ручная карточка и GeoJSON. Они не заменяют требуемый автоматический поиск. Новые подключения реализуются после подтверждения API, условий и доступа.

Распознавание изображений/OCR и восстановление пароля по почте не подключены. Текстовый PDF извлекается эвристиками: поля всегда требуют проверки. Скан без текста остаётся для ручного заполнения.

Печатный PDF содержит координаты и ссылку на карту; графическое изображение карты в отчёт пока не встроено. Полигональная область рисования заменена прямоугольником по двум углам. Фильтр названия территории работает по названию, полноценный административный справочник районов и населённых пунктов предстоит подключить.

Браузерная QA в среде сборки недоступна: инструмент cua_repl.js не установлен. Выполнены сборка и автоматические тесты доменной логики/API. Для массового коммерческого запуска нужны нагрузочная проверка, нормализованная схема данных и резервное копирование размещённой базы.

## Подключение поставщика данных

Сервер поддерживает адаптер нормализованных кандидатов: переменная `LAND_PROVIDER_URL` (HTTPS), необязательный секрет `LAND_PROVIDER_TOKEN`. Не добавляйте секреты в Git.

Сервер передаёт POST JSON: region, territory, kind, usages, minArea, maxArea, bounds. Ответ:

```json
{"candidates":[{"source":"https://provider.example","sourceId":"stable-id","region":"Калужская область","kind":"unformed","settlement":"Название населённого пункта","address":"Описание","usage":"ИЖС","area":10,"lat":54.51,"lng":36.26,"inSettlement":true,"auction":false}]}
```

Территория и правовые критерии должны быть проверены провайдером. Кандидат всё равно создаётся с непроверенными правовыми полями. Приложение не подменяет отсутствие данных подтверждением свободы участка. Повторный source + sourceId связан с постоянным ID.

## GeoJSON

FeatureCollection с геометрией Point или Polygon. В properties обязательны region, kind (`unformed` / `formed`), settlement, usage (`ИЖС` / `ЛПХ` / `Садоводство`), area (сотки); необязательны address, cadastre. Импорт ограничен 200 объектами, все проверки остаются непроверенными.

## Архитектура

React + Vite, Leaflet; серверный API на Web Request/Response. Локальный адаптер Node.js + SQLite; размещение — Cloudflare Worker + D1 + R2. Все операции требуют идентификации. Запись использует контроль версии для защиты от одновременного перезаписывания. PDF разделены по владельцу. До коммерческого этапа требуется замена единого JSON-состояния на нормализованные таблицы для больших объёмов.

В Sites авторизация принадлежит платформе. Электронная почта и пароль реализованы для отдельного локального запуска; вход по почте и паролю на самостоятельном публичном хостинге и почтовое восстановление требуют отдельной конфигурации HTTPS/SMTP.


## Подключение Mail.ru и подтверждение почты

1. Запустите локальную программу и откройте http://127.0.0.1:8787/account/email .
2. В Mail.ru создайте пароль для внешнего приложения: https://help.mail.ru/mail/faq/password/external/ . При необходимости разрешите SMTP в настройках безопасности.
3. Укажите полный адрес отправителя и пароль приложения на странице настроек Навигатора. Обычный пароль от почты не используйте.
4. Нажмите «Проверить и сохранить подключение», затем «Отправить письмо подтверждения».
5. Откройте письмо на том же компьютере, где работает Навигатор. Перейдите по ссылке и нажмите «Подтвердить почту».

Ссылка действует 24 часа, одноразовая; повторная отправка отменяет предыдущую ссылку после принятия нового письма SMTP-сервером. Просмотр ссылки не подтверждает адрес автоматически — требуется кнопка, чтобы почтовый сканер не выполнил подтверждение. Получатель — адрес существующего кабинета, отправитель — подключённый ящик Mail.ru. Адреса могут различаться.

SMTP использует smtp.mail.ru:465 с TLS. Пароль приложения хранится локально в `.data/mail-settings.json`, на Unix с правами 0600; на Windows доступ определяется правами пользовательской папки. Файл не шифруется приложением. Не публикуйте `.data` и резервные копии. Пароль не возвращается в HTML/API и не записывается в Git. Не отправляйте его в чат.

Принятие SMTP-сервером не гарантирует доставку во входящие. Если письма нет — проверьте «Спам» и настройки Mail.ru. Без настроенного ящика реальная отправка не проверена; автоматические тесты используют тестовый транспорт и не отправляют письма.

Изменение относится к локальной версии. Размещение Sites продолжает использовать вход ChatGPT и не получает SMTP-пароль. Восстановление пароля по почте пока не реализовано.

## Обновление на Windows

Скачайте Update-Navigator.cmd из папки navigator на GitHub. Закройте окно работающего сервера и запустите файл двойным щелчком. Он скачает исходники, сохранит `.data`, сделает локальную копию данных в `.data-backups`, установит зависимости и соберёт приложение. Копирование не удаляет старые данные. Скрипт Windows подготовлен, но не исполнялся в Linux-среде сборки.


## НСПД: проверка подключения с локального компьютера

В «Источники и доступ» добавлена панель «НСПД · подключение и слои». Она проверяет доступ к карте, поиску и выбранным категориям; сохраняет результаты и выгружает диагностический JSON без учётных данных. Полное описание: [docs/NSPD_CONNECTION.md](docs/NSPD_CONNECTION.md).

Существующий поиск свободных участков ещё не подключён к этим ответам: сначала необходимо подтвердить доступность данных, структуру и полноту. Скриншот видимых слоёв и успешный вход в браузере не доказывают возможность запросов Node.js. Пользовательский отчёт подтвердил получение 4 объектов ЕГРН и пустые ответы схем/полигонов в проверочной области. Геометрия и значения атрибутов в прежний краткий отчёт не включались.

Для запуска требуется Node.js 24+. Команда npm start использует системное доверие сертификатам и настройки прокси окружения. Проверку TLS не отключаем.


## Windows: запуск без чёрного окна

Скачайте `Start-Navigator-Hidden.vbs` и запустите двойным щелчком. Он найдёт установленную программу (либо предложит выбрать папку), сохранит свою копию в `scripts/windows-launcher.vbs`, создаст настоящие ярлыки «Земля Навигатор» и «Остановить Навигатор» на рабочем столе, запустит Node.js со скрытым окном и откроет браузер после ответа сервера.

Скрывается окно, процесс продолжает работать. Закрытие браузера не останавливает сервер. После перезагрузки компьютера нужно снова открыть ярлык. Автозагрузка Windows не создаётся.

Перед обновлением используйте «Остановить Навигатор», завершив текущие операции. Сценарий остановки после подтверждения завершает только процесс node.exe, командная строка которого содержит точный абсолютный путь к server/local.mjs этой установки. Другие Node-приложения не завершаются. Обычный сервер, ранее запущенный относительной командой npm start, может потребовать закрытия своего окна вручную.

Загрузки, база и документы не перемещаются и не удаляются. Для просмотра ошибки запуска остаётся Start-Navigator.cmd. Сценарий использует встроенный Windows Script Host; если он недоступен, используйте обычный запуск. В Linux-среде выполнение VBS недоступно: проверены формат файла и логика, фактический запуск требует проверки на Windows. Читаемый исходник: docs/windows-launcher-source.txt.


## Снимки геометрии НСПД — контрольная точка 21.11.2026

Добавлены серверное хранение исходной геометрии и разрешённых атрибутов, последние три версии снимка на слой, нормализация Polygon/MultiPolygon из EPSG:4326 и EPSG:3857. Если CRS не указан, возможное преобразование проверяется по области запроса и помечается как предварительное; нераспознанная геометрия на карту не выводится. Исходные координаты сохраняются отдельно от преобразованных.

В панели НСПД появился блок «Реальные объекты источника»: выбор слоя, карта контуров, таблица площади/стоимости и исходных атрибутов, подробности и выгрузка снимка JSON/GeoJSON. Нужна повторная загрузка выбранных слоёв на компьютере пользователя: старые отчёты содержат только краткие сведения, восстановить из них геометрию нельзя. Исходные объекты не становятся кандидатами автоматически.

Сопоставление геометрии учитывает отверстия и вогнутые границы. Пропущенная, нераспознанная, неполная или устаревшая категория не считается отсутствием ограничений. Обнаруженное пересечение не является автоматическим юридическим запретом. По всем результатам необходимо отдельно проверять актуальность и правовой режим.

Сборка прошла; 28 тестов проходят. Тесты нормализации, геометрии и снимков используют искусственные контрольные фигуры — это не реальные участки и не данные в кабинете. Визуальная проверка нового экрана на Windows и загрузка фактической геометрии с компьютера пользователя ещё впереди. Пользователь взял паузу: не продолжать новые изменения без возобновления работы.


## Территория пилота: выбор полигона населённого пункта

После обновления откройте «Источники и доступ» → «Найти границы около Кондрово». Программа запрашивает полигоны населённых пунктов в окрестностях, показывает их на карте и предлагает явно выбрать нужный. Прямоугольник запроса не является границей города, имена объектов не додумываются. После выбора загрузка слоёв проверяет небольшой фрагмент внутри этого полигона; весь населённый пункт ещё не обследуется. Для нового выбора требуется геометрия с указанной источником системой координат. Ошибка обновления не удаляет старые снимки, но блокирует использование устаревшего выбора для новых запросов.

Пользовательский снимок подтвердил четыре реальных контура ЕГРН и корректный пересчёт EPSG:3857 → EPSG:4326. Найденные четыре объекта не включены в кандидаты: два частные, ещё два не проходят площадь 6–20 соток. Новый поиск границ требует проверки с компьютера пользователя: из среды разработки ответ HTTP 503. Сборка и 33 теста прошли. Подтверждение Mail.ru остаётся отложенным.

Свежий Update-Navigator.cmd после сборки использует установленный скрытый запуск, если он доступен. Перед обновлением сервер нужно остановить; .data сохраняется с резервной копией. Старый уже скачанный обновлятор не заменяет сам себя во время работы — для новой логики запуска скачайте свежий файл с GitHub.


## Обход выбранной территории по частям

В локальной версии: «Источники и доступ» → выберите и примените границу → «Обход выбранной территории» → «Начать обход территории». Получение существующих участков ЕГРН выполняется в фоне, последовательно по фрагментам около 500×500 м, обрезанным по границе. Большие ответы вызывают деление фрагмента. Видны прогресс по площади, число запросов, уникальные объекты, повторы и причины предварительного отсева. На сохранённой геометрии пилота Кондрово план содержит 105 начальных фрагментов; живой обход ещё не выполнен.

«Пауза» сохраняет прогресс; «Продолжить обход» продолжает с оставшегося места. После перезапуска сервера продолжение только по кнопке. «Завершить с текущим результатом» оставляет отметку частичного обхода. Ошибки, 403/429 и тайм-ауты не превращаются в пустые успешные результаты. Запрошенную источником задержку Retry-After нельзя пропустить кнопкой продолжения. Для смены границы сначала остановите обход.

Статусы объектов: «Отсеян», «Недостаточно данных», «Проверить дальше». Последний означает только предварительное соответствие площади/собственности/назначения/геометрии, не юридическую свободу. Пропущенная собственность не считается государственной. Права третьих лиц, застройка, режимы ЗОУИТ, зоны и основания предоставления отдельно не проверены. Поиск несформированных территорий не реализован этим этапом. Основной рабочий поиск и заявления не получают эти объекты автоматически.

Повторный участок хранится одной записью с датами и числом появлений. Обходы сохраняются в SQLite, доступны история, фильтры, карта/таблица по 100 объектов и JSON-выгрузка. Сервер должен работать, вкладка может быть закрыта. На Windows новый экран и живые запросы требуют проверки; сборка и 43 теста прошли. Установленные данные .data сохраняются стандартным обновлятором с резервной копией.


## Проверки отобранных участков

После завершённого обхода откройте «Источники и доступ» → «Проверки отобранных участков» → «Проверить отобранные участки». Программа возьмёт записи «Проверить дальше» из выбранного сохранённого обхода, без повторного получения ЕГРН всего города. Для 27 объектов пилота план составляет 243 запроса: здания, сооружения, незавершённое строительство, схемы, ПМТ, ЗОУИТ, территориальные зоны, негативные процессы и справочная отметка о правах. Используются полные контуры участков.

Видны ход работы, таблица объектов, результаты каждой категории и исходные сведения. Нажмите строку участка, чтобы открыть детали. Есть пауза, продолжение после перезапуска, история и JSON кнопкой «Скачать результат проверок». Во время проверок обход и другие запросы к источнику приостановлены. Исходный обход и данные кабинета сохраняются.

«Есть пересечение» требует разбора назначения и режима. «В выборке не найдено» не означает отсутствия объекта или ограничения. Неполные ответы, точки/линии без поддержанной полигональной геометрии, неизвестный CRS и неоднозначные сопоставления остаются неопределёнными. Справочная отметка «свободные от прав третьих лиц» не подтверждает отсутствие аренды; ни один результат автоматически не делает участок юридически свободным или пригодным для предоставления без торгов. Права и ограничения требуют отдельного подтверждения.

Сборка и 55 тестов прошли. План на фактических 27 объектах проверен без сетевых запросов. Живые ответы новых категорий и экран на Windows предстоит проверить после установки обновления. Первое получение всех категорий может остановиться на паузе при ограничении доступа, тайм-ауте или ошибке источника; это не пустой успешный результат.


## Уточнение названий зон после проверок

Живые проверки 27 участков пилота завершены: 243 ответа, одна общая территориальная зона и четыре уникальные охранные зоны на трёх участках. Для уточнения откройте «Источники и доступ», в результатах проверок найдите «Подробные карточки зон» и нажмите «Уточнить карточки зон (5)». Программа использует сохранённые номера; обход и проверки участков повторять не требуется. Полученные карточки сохраняются по мере ответов. Закрытие вкладки прекращает оставшиеся запросы; отказ источника останавливает пакет.

Нажмите «Скачать сведения о зонах» для файла nspd-zones-…json. Карточка может содержать только номер, общие сведения или ошибку доступа. Она не подтверждает действующую редакцию ПЗЗ, отсутствие аренды или право получить участок без торгов. Сборка и 62 теста прошли; новый запрос и экран требуют проверки на компьютере пользователя.


## Территории для образования участка 6–20 соток

В локальной версии откройте «Источники и доступ» → «Территории для образования участка · 6–20 соток». Выберите полностью завершённый сохранённый обход, диапазон площади и цель, нажмите «Найти территории 6–20 соток». Программа использует все контуры ЕГРН, включая частные и ранее отсеянные, и ищет расчётные прямоугольники внутри границы без наложения на полученные участки. Новый обход и интернет-запросы для этого не нужны. Вычисления выполняются в отдельном потоке, есть остановка, продолжение и история.

Подборка ограничена 30 геометрическими вариантами, до одного на обследованный фрагмент. Метод выборочный, площадь приближённая; формы через границы фрагментов и раздел существующих участков не исследуются. Найденный контур не является официальной схемой или доказательством свободы земли. Цель поиска не означает допустимый ВРИ.

Выберите вариант в таблице. Кнопка «Проверить этот контур по слоям» получает восемь категорий НСПД только для выбранного контура. Доступны карта, исходные сведения, список недостающих юридических проверок, Excel, GeoJSON и JSON («Скачать результат поиска территорий», nspd-territorii-…json). Права, принадлежность земли, подъезд, действующие ПЗЗ и основание/процедура предоставления без торгов остаются для отдельного подтверждения. Варианты не переносятся автоматически в заявления или юридически пригодные участки.
