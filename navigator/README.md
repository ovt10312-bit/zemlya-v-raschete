# Земля · Навигатор

Адаптивное веб-приложение для личной работы с земельными участками. Карта, фильтры, карточки, калькулятор, история, избранное, импорт новых заявлений из Excel, разбор текстовых PDF с подтверждением и статистика.

## Открыть на своём компьютере

1. Установите Node.js 24 LTS (https://nodejs.org/).
2. Скачайте исходный код и распакуйте архив. Откройте терминал в папке с этим README.
3. Выполните последовательно:

```sh
npm ci
npm run build
npm start
```

4. Откройте **http://127.0.0.1:8787** в браузере.
5. При первом запуске создайте кабинет: почта и пароль от 12 символов. Следующие входы сохраняются на 30 дней.

Для остановки нажмите Ctrl+C. Повторный запуск: `npm start`.

Данные хранятся в `.data/` рядом с программой. Не удаляйте папку; для резервной копии остановите программу и скопируйте её целиком. JSON-выгрузка в интерфейсе не содержит исходных PDF — они входят в копию `.data/`.

Локальный сервер слушает только этот компьютер. На телефоне используйте опубликованную закрытую версию: локальный адрес 127.0.0.1 с другого устройства не доступен.

## Что работает

- 9 регионов, 6–20 соток, ИЖС / ЛПХ / садоводство; два типа поиска.
- Карта OpenStreetMap, область поиска двумя кликами, карта / таблица / совмещённый вид.
- Отдельный явно обозначенный демонстрационный режим. Примеры вымышлены и не попадают в рабочую статистику.
- Серверная история, избранное, постоянные ID и версии экономики.
- Формула меньшей медианы × 0,8 ÷ 2 × фактическую площадь; расходы и неизвестные значения отдельно.
- XLSX-экспорт с ID, проверками и аналогами; обратный импорт новых заявлений с проверкой строк и без дублей.
- PDF-отчёт через окно печати браузера: выберите «Сохранить как PDF».
- Разбор текстового PDF в браузере, хранение оригинала, редактирование полей, подтверждение одного или нескольких ответов.
- Статистика только по рабочим данным; согласование и фактическое предоставление — отдельные этапы.
- Локальный вход по почте и паролю, серверное хранение SQLite и файлов.
- Закрытое размещение Sites: вход через ChatGPT, данные в D1, PDF в R2.

## Существенные ограничения первой поставки

**Полноценный автоматический поиск свободной земли пока не подключён.** Нет подтверждённых интеграций НСПД, Авито, ЦИАН, Telegram-бота и docs.cntd.ru. Реальный запуск без провайдера сохраняет недоступность источника и не создаёт участки. Нормативная актуальность и правовая доступность автоматически не подтверждаются.

Дополнительные способы наполнения: ручная карточка и GeoJSON. Они не заменяют требуемый автоматический поиск. Новые подключения реализуются после подтверждения API, условий и доступа.

Распознавание изображений/OCR и восстановление пароля по почте не подключены. Текстовый PDF извлекается эвристиками: поля всегда требуют проверки. Скан без текста остаётся для ручного заполнения.

Печатный PDF содержит координаты и ссылку на карту; графическое изображение карты в отчёт пока не встроено. Полигональная область рисования заменена прямоугольником по двум углам. Фильтр названия территории работает по названию, полноценный административный справочник районов и населённых пунктов предстоит подключить.

Браузерная QA в среде сборки недоступна: инструмент cua_repl.js не установлен. Выполнены сборка и автоматические тесты доменной логики/API. Для массового коммерческого запуска нужны нагрузочная проверка, нормализованная схема данных и резервное копирование размещённой базы.

## Подключение поставщика данных

Сервер поддерживает адаптер нормализованных кандидатов: переменная `LAND_PROVIDER_URL` (HTTPS), необязательный секрет `LAND_PROVIDER_TOKEN`. Не добавляйте секреты в Git.

Сервер передаёт POST JSON: region, territory, kind, usages, minArea, maxArea, bounds. Ответ:

```json
{"candidates":[{"source":"https://provider.example","sourceId":"stable-id","region":"Калужская область","kind":"unformed","settlement":"Название населённого пункта","address":"Описание","usage":"ИЖС","area":10,"lat":54.51,"lng":36.26,"inSettlement":true,"auction":false}]}
```

Территория и правовые критерии должны быть проверены провайдером. Кандидат всё равно создаётся с непроверенными правовыми полями. Приложение не подменяет отсутствие данных подтверждением свободы участка. Повторный source + sourceId связан с постоянным ID.

## GeoJSON

FeatureCollection с геометрией Point или Polygon. В properties обязательны region, kind (`unformed` / `formed`), settlement, usage (`ИЖС` / `ЛПХ` / `Садоводство`), area (сотки); необязательны address, cadastre. Импорт ограничен 200 объектами, все проверки остаются непроверенными.

## Архитектура

React + Vite, Leaflet; серверный API на Web Request/Response. Локальный адаптер Node.js + SQLite; размещение — Cloudflare Worker + D1 + R2. Все операции требуют идентификации. Запись использует контроль версии для защиты от одновременного перезаписывания. PDF разделены по владельцу. До коммерческого этапа требуется замена единого JSON-состояния на нормализованные таблицы для больших объёмов.

В Sites авторизация принадлежит платформе. Электронная почта и пароль реализованы для отдельного локального запуска; вход по почте и паролю на самостоятельном публичном хостинге и почтовое восстановление требуют отдельной конфигурации HTTPS/SMTP.
