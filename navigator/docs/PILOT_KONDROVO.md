# Пилот: Кондрово, Калужская область

Дата: 21.11.2026. Пользователь выбрал Калужскую область и поручил самостоятельно выбрать любую небольшую территорию. Выбран город Кондрово. Это технический пилот, не рекомендация о ликвидности или вероятности получения земли.

Критерии: только границы населённого пункта, 6–20 соток, ИЖС/приусадебное ЛПХ/садоводство, физическое лицо, предоставление без торгов. Целевые режимы — образование новых участков и уже образованные государственные/муниципальные участки. Граница города, права и возможность предоставления пока не подтверждены.

## Проверка подключения

Из среды разработки выполнены обычные HTTPS-запросы с проверкой TLS и штатными сетевыми настройками:

- https://nspd.gov.ru/ — HTTP 503.
- https://nspd.gov.ru/map — HTTP 503.
- GET https://nspd.gov.ru/api/geoportal/v2/search/geoportal с query=Кондрово и thematicSearchId=4 — HTTP 503, проверено 21.11.2026.

Форма поискового запроса изучена в открытой библиотеке pynspd: https://github.com/yazmolod/pynspd . Она не является официальной документацией API НСПД. Стабильность интерфейса и условия использования не подтверждены. Библиотека не устанавливалась и не запускалась: изучены исходные тексты из wheel PyPI.

503 не доказывает отсутствие участков и не позволяет заключить, что сайт недоступен с компьютера пользователя. Источник ошибки (сам сервис или промежуточная инфраструктура) не установлен. Не применялись отключение TLS, обход защит, подмена адресов или пользовательские cookies.

## Фактический результат

Реальные кандидаты, кадастровые номера, контуры, свободные территории и нормативные ставки не получены. Изменений в рабочий поиск не вносилось. Демонстрационные примеры не должны выдаваться за результаты пилота.

## Следующий шаг

Проверить обычное открытие https://nspd.gov.ru/map в браузере пользователя на компьютере, где работает Навигатор. Если открывается — проверить карту Кондрово и доступность нужных слоёв. Затем подтвердить способ программного доступа к данным. Не просить пароль Госуслуг, cookies или токены в чате.

После подтверждения доступа: получить официальную геометрию границ, участков и ограничений; только затем реализовывать отбор. Для несформированных территорий отсутствие учтённого контура не означает юридической свободы.
