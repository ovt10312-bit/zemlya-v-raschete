## Согласованные требования

### Назначение и регионы

Внутреннее адаптивное веб-приложение для пользователя-физлица, впоследствии возможен платный продукт для других пользователей. Только получение земли без торгов, без аукционов и автоматической отправки юридически значимых заявлений.

Первая география: Калужская, Тульская, Ленинградская, Свердловская, Тюменская (без ХМАО и ЯНАО), Челябинская, Тверская, Владимирская области и Республика Башкортостан. В будущем — расширение на всю Россию без переписывания приложения.

### Поиск и отображение

- Два раздела: территории для образования участков; образованные государственные/муниципальные участки с кадастровыми номерами.
- Только в границах населённых пунктов, 6–20 соток, ИЖС / приусадебное ЛПХ / садоводство.
- Автоматический поиск по кнопке, без расписания. Территория через выбор из справочника и выделение на карте, несколько территорий в целевой версии.
- Три представления: карта, таблица, карта и таблица вместе. Полноценная работа с компьютера и телефона.
- Ориентир полезности: до 20 перспективных вариантов за день работы при наличии данных; не заполнять выдачу неподходящими ради количества. Цель экономии около 7 часов в неделю из бизнес-профиля, фактический эффект пока не измерен.
- Постоянный внутренний ID; собственный кадастровый номер не путать с ориентиром соседнего участка.
- Подробная карточка, избранное, Excel .xlsx и PDF. Сохранять все рабочие поиски, а не только избранное. Уникальные участки не дублировать в статистике.

### Проверки и источники

Проверки: чужие схемы, ЗОУИТ и другие ограничения, затопление/подтопление, территориальная зона и регламент, подъезд, права/обременения, основание предоставления без торгов физлицу. Неизвестность не считать отсутствием ограничения или юридической свободой.

Источники целевого автоматического получения: НСПД и официальные данные, Авито, ЦИАН, @rosreestdeals_bot, docs.cntd.ru и официальное опубликование нормативных актов. У пользователя есть личный кабинет docs.cntd.ru; доступ из приложения не подключён. Приоритет бесплатных способов, платные отдельно согласовывать.

Документы и ставки проверять на текущую дату расчёта: действие, отмена, редакция, даты вступления изменений, муниципалитет/собственность/ВРИ/основание/статус физлица. Сохранять документ, пункт, источник и дату проверки. Если актуальность не подтверждена — явно указать это. Одну ставку нельзя произвольно применять ко всей области.

### Экономика

Использовать модель исходного калькулятора «Земля в расчёте»:

1. Медианная цена за сотку отдельно для Авито, ЦИАН и реальных сделок.
2. Меньшая из доступных медиан × 0,8 ÷ 2 × фактическая площадь в сотках = предварительная цена права аренды.
3. Отдельно расходы, расчётная чистая прибыль, доходность; неизвестные расходы не заменять нулём.

Минимум три сопоставимые сделки за последние 12 месяцев. При меньшем количестве участок показывать с пометкой «Недостаточно данных для оценки ликвидности». Цена объявления не равна цене сделки.

Фактическая площадь 6–20 соток, фиксированные расходы не масштабировать. В существующей модели учитывается полная годовая аренда. Кадастровая стоимость несформированного участка — ориентир по соседним, а не собственная установленная стоимость.

### Заявления и ответы

- Начинаем новую историю с нуля, старый Excel не импортируем.
- После подачи пользователь загружает актуальный Excel новых заявлений. Связь по столбцу «ID участка», номер и дата подачи, без дублей при повторном импорте.
- Основные ответы администраций — PDF с текстом. Извлечь поля, показать исходник и редактирование.
- Сохранять решение в итоговую статистику только после «Подтвердить и сохранить» или подтверждения выбранных проверенных строк.
- Отдельные даты подачи, документа и получения. Не додумывать отсутствующие.
- Отказ, предварительное согласование, предоставление, договор аренды и регистрация права — разные этапы. Предварительное согласование не считать полученным участком.

### Внешний вид и доступ

Компактный рабочий интерфейс, карта/фильтры/таблица. Зелёный для основных действий, синий для информации и стабильности, оранжевый для акцентов и внимания. Название и цвета в дальнейшем можно менять.

Закрытый доступ, почта/пароль в локальной версии, сохранение сессии. Будущее разделение данных разных пользователей. В размещении Sites применяется платформенный вход ChatGPT.

## Что реально реализовано и ограничения

Реализованы интерфейс, карта OpenStreetMap, демо-примеры с явными метками, серверная история, избранное, ID, калькулятор, XLSX, печать PDF, импорт новых заявлений, извлечение текста PDF, подтверждение решений, статистика, локальная авторизация, запуск и обновлятор Windows.

**Автоматический поиск реальных свободных участков ещё не подключён.** Реальный запуск без провайдера сохраняет статус недоступности и не создаёт вымышленных результатов. Все демо-участки вымышлены, не входят в рабочую статистику. Есть ручное добавление, GeoJSON и контракт внешнего LAND_PROVIDER_URL — это не заменяет подключение НСПД и остальных источников.

Полный административный справочник и несколько областей выделения не реализованы; сейчас регион, текст территории и один прямоугольник двумя кликами. OCR сканов не реализован. PDF-отчёт через печать, содержит координаты и ссылку, без встроенного изображения карты. Нормативные основания вводятся вручную, автоматической актуализации нет. Восстановление пароля по почте не реализовано. Состояние хранится как JSON в SQLite/D1 с контролем версии; для больших объёмов нужна нормализация.

До этого в Linux-среде отсутствовал браузерный QA-инструмент; пользовательскими скриншотами теперь подтверждены Windows-запуск, отображение интерфейса и установка почтового обновления. Сквозные действия с реальными источниками и реальная доставка SMTP не проверены.

## Последнее изменение: Mail.ru

- `server/mail.mjs`: SMTP smtp.mail.ru:465, TLS; nodemailer; настройка авторизованным пользователем.
- `/account/email`: подключение отправителя, сохранение после SMTP-проверки, запрос подтверждения.

- У существующего кабинета добавляется поле email_verified_at без пересоздания аккаунта и смены пароля.
- Одноразовый случайный токен, в БД только хеш, срок 24 часа. Повторная отправка через минуту; успешная новая отправка отменяет старую ссылку.
- GET ссылки показывает страницу, подтверждение только POST по кнопке — почтовый сканер не подтверждает адрес посещением ссылки.
- Ссылка localhost должна открываться на том же компьютере при работающем сервере. Принятие SMTP-сервером не гарантирует доставку во входящие.
- Пароль для внешнего приложения создаётся в настройках безопасности Mail.ru. Источники: https://help.mail.ru/mail/faq/password/external/ и https://help.mail.ru/mail/login/mailer/ . При необходимости включить доступ SMTP.
- Пройдены сборка и 14 тестов: формулы, API, локальный вход, сохранение, миграция существующего кабинета, непубликация секрета, токены, срок, повторная отправка, ошибка SMTP. Тестовый транспорт не отправляет реальные письма.
