# Автоматическое получение цен в Comet

Однократная установка после обновления Навигатора:

1. Открой Comet и страницу `chrome://extensions` (или меню расширений браузера).
2. Включи «Режим разработчика», нажми «Загрузить распакованное расширение».
3. Выбери эту папку `navigator\browser-extension` целиком, где находится manifest.json. Не отдельный файл.
4. Открой в Comet `http://127.0.0.1:8787`, войди в свой локальный кабинет. Данные кабинета сохраняются на локальном сервере; в другом браузере нужно войти заново.
5. Карточка → Экономика → «Получить цены Авито и ЦИАН».

При следующих поисках нужна только эта кнопка. Открывать объявления, переносить задания или таблицы не требуется. Во время поиска вкладку Авито не закрывай. Если папку расширения переместить, понадобится загрузить его заново; при обновлении файлов нажми обновление расширения на странице расширений.

Расширение выбирает «Недвижимость → Земельные участки», точный населённый пункт с регионом, читает до 25 карточек списка. Никаких платных API и запросов к нейросети. ЦИАН запускается параллельно обычным загрузчиком Навигатора; автоматический поиск вне пилотного Кондрово у него ещё не завершён. Сервер проверяет присланные карточки, калькулятор использует населённый пункт и ВРИ без требования квартала. Сохранение расчёта выполняется автоматически.

Доступ расширения: только публичные страницы Авито и мост на localhost:8787/127.0.0.1:8787. Расширение не читает cookies, пароли, документы, сообщения или профиль браузера. Запрос геолокации не требуется; обычное окно сайта можно закрыть. При проверке человека или блокировке IP сбор останавливается, защиту сайта расширение не снимает. Пустой/неподтверждённый результат не означает отсутствие участков.

Проверка разработчика: серверные тесты и логика чтения реального DOM тестовых страниц прошли. Установка в настоящий Comet и получение настоящих цен Авито ещё требуют проверки. В управляемом облачном браузере установка расширений запрещена администратором; тест цепочки использовал имитацию API Chrome, а не установленное расширение.
